# Machine Learning Lab Tasks

A structured collection of core machine learning workflows implemented in Python using `scikit-learn`, `pandas`, `seaborn`, and `matplotlib`. This repository covers end-to-end tasks from raw dataset preprocessing and exploratory data analysis (EDA) to model training, evaluation, comparison, and hyperparameter tuning.
